# 2048 Web Version Design

## Overview

Convert the existing terminal-based 2048 game (`game.py`) into a browser-playable single HTML file. No dependencies, no server required — double-click `index.html` to play.

## Visual Style

- **Background:** `#fafafa`
- **Board background:** `#e8e8ed`
- **Font:** `-apple-system` (SF Pro on Mac), 700 weight for title
- **Tile colors:** Graduated from light gray (low values) to Apple green (`#30d158`) at high values
  - 0: transparent / board color
  - 2, 4: `#fafafa` / `#f0f0f0` (light gray)
  - 8, 16: light green tint
  - 32, 64: medium green
  - 128, 256: `#30d158` (Apple green)
  - 512, 1024, 2048: deep green (`#25a244`, `#1a7a32`)
- **No shadows, no gradients, no decorative borders** — every element earns its place
- **Border radius:** 8px on board, 6px on tiles

## Layout

Single centered column, vertically centered on screen.

```
[ 2048 ]                  [ SCORE 1024 ] [ BEST 2048 ]
┌─────────────────────────────────────────┐
│  [ ]  [ ]  [64] [ ]                     │
│  [ ]  [128][ ]  [ ]                     │
│  [ ]  [ ]  [ ]  [ ]                     │
│  [ ]  [ ]  [ ]  [ ]                     │
└─────────────────────────────────────────┘
                                  [New Game]  [Undo]
```

- Title "2048" left-aligned, bold, large
- SCORE and BEST as small pill cards, right-aligned same row
- Board below, fixed width (~420px), centered
- New Game + Undo buttons bottom-right, minimal text style

## Interaction

| Input | Action |
|-------|--------|
| Arrow keys | Move tiles |
| Mouse drag on board | Move tiles (swipe direction) |
| Touchpad swipe | Move tiles |
| U key | Undo one step |
| Undo button | Undo one step |
| New Game button | Reset board |

- Drag threshold: 30px minimum to register as a swipe
- Undo is limited to one step (same as terminal version)

## Animation

- Tile movement: CSS `transform` transition, 80ms ease
- Tile merge pop: brief scale pulse (110% → 100%), 100ms
- New tile appear: fade in + scale from 50% → 100%, 120ms
- No animation on New Game reset

## Game Logic

Port directly from `game.py`:
- `slide_row` — merge logic
- `move` — all four directions
- `has_moves` — game over detection
- `add_tile` — 90% chance of 2, 10% chance of 4
- Score accumulates on merges; best score persists in `localStorage`

## File Structure

```
2048/
  index.html     ← entire game (HTML + CSS + JS inline)
  game.py        ← original terminal version (untouched)
```

## Out of Scope

- Sound effects
- Online leaderboard
- Mobile app packaging
- Dark mode toggle
